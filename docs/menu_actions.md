# 菜单使用说明

菜单按六类组织，直接复用工作区已有功能，避免重复参数窗口。

| 菜单 | 主要操作 |
| --- | --- |
| 文件 | 新建、打开、保存、另存为、关闭场景／仿真文件；按工作区保存 EPSX 或导出 MP4、XLSX、CSV；编辑器设置和退出 |
| 编辑 | 撤销、重做、剪切、复制、粘贴、批量删除、全选和取消选择 |
| 场景 | 七项可叠加预设、C 控制程序、属性面板与求解设置面板 |
| 运行 | 求解／取消求解、回放播放／暂停、停止并回到起点、前后逐帧 |
| 视图 | 工作区切换、适配场景／曲线、当前视口网格与坐标轴、旧实时仿真面板 |
| 帮助 | 快捷键和菜单说明、关于软件、关于 Qt |

F1 可查看快捷键。菜单会根据当前工作区、对象选择、撤销历史、剪贴板及运行状态决定是否可用。文字或代码输入获得焦点时，Ctrl+Z/Y/X/C/V/A、Delete 和 Home 交给文本控件；模态窗口打开时暂停主窗口的菜单快捷键。

退出菜单和窗口关闭按钮共用未保存检查：逐个询问有修改的场景，保存或放弃后继续，取消保存或选择“取消”会终止退出。关闭最后一个标签后产生的默认空场景保持未修改状态。

## 本次维护

- 修复子菜单快捷键未遍历、丢失完整路径以及未继承父级禁用状态的问题。
- 修复子菜单方向键索引错误、展开边界计算使用菜单栏高度和弹窗未回收到复用池的问题。
- 菜单操作执行前关闭菜单，防止新弹出的窗口失去焦点。
- 用可持久保存的等宽字体、字号设置替换空的偏好设置入口。
- 撤销／重做状态随标签切换、修改、加载及历史操作更新。
- 批量删除只记录一次撤销；剪切后清除选择，粘贴后选中新对象。

## 验证范围

`EgretEditorTests` 覆盖子菜单快捷键路径、父级禁用状态、键盘导航索引、弹窗边界及复用，撤销／重做状态和关闭最后标签后的默认文档状态。原有预设、C 编辑器和场景往返测试继续运行。

同时执行 QML 字节码编译、Release 构建及 C 场景求解、加载时间和场景设置回归。完整 GUI 菜单交互及多标签退出流程仍需在实际 Windows 运行环境中确认。
