# 滑块与受拉木板

取向右为正，初始木板左端为 x=0，滑块为 x=1 m。初始速度均为零，拉力持续作用。

## 解析解

滑块与木板间的滑动摩擦力为 f₁=μ₁m₁g=3 N，滑块加速度 a₁=3 m/s²。
分离前，地面对木板的支持力为 (m₁+m₂)g=40 N，因此地面摩擦力为 f₂=8 N。
木板的加速度为

\[
a_2=\frac{F-f_1-f_2}{m_2}=\frac{26-3-8}{3}=5\ \mathrm{m/s^2}.
\]

滑块相对木板向左移动 1 m 后分离：

\[
1=\tfrac12(a_2-a_1)t_1^2,\qquad t_1=1\ \mathrm{s},\qquad v_1=a_1t_1=3\ \mathrm{m/s}.
\]

分离时木板速度为 5 m/s；木板左端与滑块均位于 x=2.5 m。
滑块随后在地面减速，加速度为 −μ₂g=−2 m/s²；再经过 τ=3/2 s 停下，即总时间 t=2.5 s。
分离后木板对地面的压力降至 30 N，地面摩擦降至 6 N，故木板加速度变为 (26−6)/3=20/3 m/s²。

\[
x_{\mathrm{block}}=2.5+3\tau-\tau^2=\frac{19}{4}=4.75\ \mathrm m,
\]
\[
x_{\mathrm{left}}=2.5+5\tau+\frac{10}{3}\tau^2=\frac{35}{2}=17.5\ \mathrm m,
\]
\[
\boxed{d=x_{\mathrm{left}}-x_{\mathrm{block}}=\frac{51}{4}=12.75\ \mathrm m}.
\]

因此三问答案依次为 **5 m/s²、3 m/s、12.75 m**。

用于曲线比对的完整水平轨迹为：

| 阶段 | 滑块 x/m | 滑块 vx/(m/s) | 木板左端 x/m |
|---|---|---|---|
| 0≤t≤1 | 1+1.5t² | 3t | 2.5t² |
| 1≤t≤2.5，τ=t−1 | 2.5+3τ−τ² | 3−2τ | 2.5+5τ+(10/3)τ² |
| t≥2.5 | 4.75 | 0 | 2.5+5τ+(10/3)τ² |

## 三维系统中的建模

- 水平为 x，竖直为 z，全部物体的 y、vy、角速度均为零；使用非弹性接触。
- `rotation_enabled: false` 使用具有碰撞形状的平动物体，保留质量与平动碰撞响应。
- 木板设置 `constant_force: [26,0,0]`，恒力在 Verlet 每次力重算时重新施加。
- 重力为 `[0,0,-10]`；地面质量为零，木板与滑块质量分别为 3 kg、1 kg。
- 接触摩擦系数采用几何平均规则。木板、滑块材料系数均为 0.3，地面为 2/15，使三对接触的系数分别为 0.3、0.2、0.2。题目已规定相对滑动，静摩擦系数在本场景取对应动摩擦系数。
- `sliding_block_board.epscene` 使用 2×10⁻⁶ m 厚度与滑块水平尺寸，步长 0.1 ms。
- `sliding_block_board_thin.epscene` 使用 2×10⁻⁸ m 厚度与滑块水平尺寸，步长 0.01 ms，用于验证理想薄板、质点极限。物体宽度非零，但所有运动都在 xz 平面内。

## 发现的问题与修正

1. 场景入口缺少指定物体持续恒力与禁止转动配置：增加上述两个可序列化字段，并在属性面板未提供字段时保留原配置。
2. 求解器惯性缓存忽略 `hasRotation()`：质点仍会得到非零逆惯量，接触求解产生非物理角速度与侧向漂移。现对无转动自由度实体清零逆惯量。
3. 接触流形固定使用 0.2 mm 容差：当木板比容差更薄时，滑块可能被尚未接触的地面支撑。现将接触容差限制在最短特征尺寸的 0.1% 内，并按尺寸限制位置穿透容差。
4. 极薄盒体与大地面经通用 GJK/EPA 路径时出现错误接触冲量。无角速度盒体改用连续 SAT；具有转动的盒体及其它形状保留原路径。增加薄盒体落地时刻、法线及远离地面无碰撞检查。

诊断前已读取主日志末 50 行并搜索错误级别。该日志最后更新时间为 2026-10-29，不包含本次离线求解；本次复现依据为 EPSX 状态、离线标准输出及自动回归结果。

## 数值结果与误差

两种精度均运行 2.6 s，EPSX 每 1 ms 采样。测得木板滑动阶段加速度分别为 5.0000000385、5.0000003661 m/s²。

| 场景 | t=1 s 的滑块速度/(m/s) | t=2.5 s 的距离/m | 该时刻距离相对误差 |
|---|---:|---:|---:|
| 普通精度 | 2.9993998846 | 12.7523332641 | 0.01830% |
| 薄板极限 | 2.9999389018 | 12.7502362578 | 0.001853% |
| 解析解 | 3 | 12.75 | 0 |

上表比较固定时刻；EPSX 中首次观测到速度归零均为 t=2.5 s，但采样间隔为 1 ms，不能把它当成精确停止事件。
使用停止前两个实测速度拟合局部减速度后，薄板极限场景停止时间估计为 2.49994945 s，停止距离约 12.74947803 m，相对误差约 0.0041%。该插值使用实测速度，不以解析解替换求解结果。
完整求解器回归还会在每个计算步检查分离与停止事件，避免采样遗漏。

逐计算步测得：

| 场景 | 分离时间/s | 分离速度/(m/s) | 停止时间/s | 停止时距离/m |
|---|---:|---:|---:|---:|
| 普通精度 | 0.9999 | 2.99939988457 | 2.4995 | 12.7448338803 |
| 薄板极限 | 0.99999 | 2.99993890183 | 2.49995 | 12.7494862639 |

薄板极限停止距离的相对误差为约 0.00403%，与仅对固定 t=2.5 s 比较得到的误差不同。
Release 构建通过；`EgretContactTests` 与 `EgretEditorTests` 共 2 项 CTest 全部通过，包含原有完全弹性盒体、圆柱弹跳及阻力停稳回归。完全弹性场景能量最大相对偏差约 2×10⁻¹³。

有限几何会产生边缘接触与落地冲量，接触冲量和积分也有时间离散误差。共同缩小物体厚度、滑块尺寸与步长后误差减小，符合向理想题目收敛的预期。当前结果是三维碰撞系统的数值近似，未将理论轨迹写入仿真。

## 复现与回放

在项目根目录的 PowerShell 中执行：

```powershell
cmake --build build --config Release --target Egret_Physics Egret_Contact_Tests Egret_Editor_Tests
ctest --test-dir build -C Release -R 'EgretContactTests|EgretEditorTests' --output-on-failure
./build/Release/Egret_Physics.exe --solve demo/sliding_block_board_thin.epscene --duration 2.6 --step 0.01 --sample 1 -o build/sliding_block_board_thin.epsx
python tools/analyze_sliding_block.py build/sliding_block_board_thin.epsx
./build/Release/Egret_Physics.exe --parse epsx 2500 build/sliding_block_board_thin.epsx
./build/Release/Egret_Physics.exe --play build/sliding_block_board_thin.epsx
```

`analyze_sliding_block.py` 导出同名 CSV 和 JSON，检查解析值误差、二维性和禁止转动。微小物体的可视尺寸很小，可结合轨迹与数据分析工作区核对；GUI 显示效果及用户本地日志仍需用户最终确认。
