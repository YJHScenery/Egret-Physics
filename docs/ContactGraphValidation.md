# 接触修复与同步碰撞图验证记录

## 实际改动

物理输入首先需要确定：原 `demo/demo_world.epscene` 与 `demo/test.epsx` 的实体恢复系数均为 1，文件没有空气阻力约束。纯竖直、无切向滑动的完全弹性面碰撞不应被强行停住。历史文件中衰减、横向漂移与持续抖动不能作为理想弹性运动的正确目标。

本次同时解决了几个直接影响复现的实现问题：

- 盒体、圆柱、圆柱壳的惯性矩阵非对角项未清零；凸网格惯性和质心偏移累加器、实体合力累加器也存在未初始化数据。回归曾捕获到该问题引起的非有限角速度，现已显式清零。
- 细棒的零主惯量不能直接逆矩阵；缓存改为对称谱分解伪逆。
- 偏心平面接触使用真实面法线和多点流形，避免质心连线带来横向冲量。
- 法向整体求解、固定恢复目标、允许撤回过量冲量、二维摩擦圆锥及同步位姿投影。
- 补充扫掠碰撞候选和 TOI 更新；将已存在的支撑接触纳入当前求解，并避免步末重复恢复。
- 离线与 GUI 的接触休眠改用仿真时间，支持撤去支撑及受力变化唤醒；修复唤醒日志中引用已删除快照的悬空引用。

详细公式、来源 URL、数值方法和首版限制见 `ContactGraphSolverDesign.md`，尤其第 11 节。

## 构建与自动回归

环境：Windows、Visual Studio 18 2026，Release。

```powershell
cmake --build build-verify --config Release --target Egret_Contact_Tests Egret_Physics
ctest --test-dir build-verify -C Release -R '^EgretContactTests$' --output-on-failure
```

主程序与独立接触测试目标构建成功。CTest 的 `EgretContactTests` 通过；本次没有宣称旧测试目标全部通过。旧 `test_ccd.cpp` 仍引用已迁走的头文件，本轮通过独立目标避免将这个问题与新算法混在一起。

回归覆盖：

1. 偏心盒体/地面、圆柱端面/地面、多点流形、A/B 交换后法线反转、分离判定。
2. 三体闭环、重复边与反序约束，解的一致性和质量中心保持。
3. 48 条边共享一个动态节点的图，共 49 个动态质点；共享静态地面的两个独立实体仍保持两座岛。
4. 固定端杆约束与质量加权位置恢复。
5. 低速不回弹、完全弹性恢复目标、摩擦冲量模长不超过圆锥界。
6. 离线无需渲染回调的接触休眠、撤走地面后唤醒、外力变化唤醒、重力下无支撑低速物体不冻结。
7. 盒体和圆柱的完整求解器仿真：无阻力弹性各 10 秒、有阻力各 40 秒，步长 0.5 ms。四项均没有安装休眠策略，因此带阻力停稳不是通过冻结掩盖速度残差。

| --- | ---: | ---: | ---: | ---: |
| 盒体 | 693000 | 692999.99999987939 | 693000.00000000873 | 1.741e-13 |
| 圆柱 | 603000 | 602999.99999988172 | 603000.00000000873 | 1.962e-13 |

这些仅是对称、单体、平行面碰撞的测量，不是复杂多体同时冲击的能量守恒证明。带阻力的无休眠测试要求最后五秒高度振幅小于 1e-6、末态线速度与角速度模长小于 1e-7，均通过。

## EPSX 验证

在算法确定和实现之后生成，没有覆盖用户提供的历史文件。

```powershell
Set-Location build-verify
.\Release\Egret_Physics.exe --solve ..\demo\demo_world.epscene --duration 60 --step 0.5 --sample 10 -o contact-demo-final.epsx
.\Release\Egret_Physics.exe --solve ..\demo\contact_plane_drag.epscene --duration 60 --step 0.5 --sample 10 -o contact-plane-drag.epsx
```

两个文件均推进 120000 步、写出 6001 帧。一次本机运行分别耗时约 2.82 秒和 6.28 秒；这是单次端到端耗时，不是跨引擎或大型碰撞岛的性能基准。

`demo/contact_plane_drag.epscene` 是新建的受控场景：保留原地面、盒体、圆柱和重力，加入线性空气阻力，平动系数为 5，并开启旋转阻力。保持原恢复系数为 1，初态与尺寸不变。JSON 的 `_documentation` 字段只记录场景用途，不参与物理求解。

统计工具：`tools/analyze_contact_simulation.py`。检查魔数、格式、记录范围、有限数值、文件头及全部块 CRC-32C，统计最后五秒的 501 个采样点。

### 带阻力的最终结果

| 实体 | 高度振幅 | 线速度 RMS | 角速度 RMS | 尾段休眠采样数 |
| --- | ---: | ---: | ---: | ---: |
| 盒体（ID 2） | 0 | 0 | 0 | 501 / 501 |
| 圆柱（ID 9） | 0 | 0 | 0 | 501 / 501 |

末态盒体中心约 `(300,400,114.998975293)`，圆柱中心约 `(-100,-100,164.998975378)`。地面顶面为 z=65，剩余穿透约 0.001025，接近配置 slop=0.001；当前目标是容差内稳定接触，不能宣称严格零穿透。

### 原无空气阻力场景的最终结果

盒体与圆柱保持竖直弹跳，没有因冻结而被强行停住。最后五秒的角速度 RMS 分别约为 `8.60e-14` 与 `4.07e-13`，横向位置接近初态。高度振幅分别约 384.967 与 234.432，符合高恢复系数、缺少空气阻力时仍存在宏观运动的性质。

历史 `test.epsx` 中两者最后五秒角速度 RMS 约为 0.006735 和 0.07358，并有明显横向漂移。该文件来自历史可执行版本，只能作为用户原问题的记录，不能当成与本次二进制仅有单一变量差异的严格对照实验。

## 输出位置与结论边界

- `build-verify/contact-demo-final.epsx`：原场景重跑。
- `build-verify/contact-plane-drag.epsx`：带阻力受控场景，可直接用播放器查看。
- `build-verify/contact-baseline.json`、`contact-demo-final.json`、`contact-plane-drag.json`：带 CRC 检查的采样统计。
- `build-verify/contact-tests-final.log`：测试输出和精确能量记录。

目前的证据支持：平行盒面与圆柱端面在有阻力时可以稳定停住；无阻力弹性单体不会通过非物理冻结来消除弹跳；同步碰撞图在已测试的闭环、冗余和高连接结构上能够整体恢复位置。

尚需用户检查播放器中的视觉效果。采样曲线本身不能排除帧间高频振荡，因此报告同时提供每个求解步执行的无休眠回归。尚未完成所有形状组合、极端质量比、任意大岛和复杂多体恢复模型的全面验证；有限迭代残差、其它旧约束类型、跨帧缓存及最坏 O(N²) 的扫掠候选补充仍是明确边界。
