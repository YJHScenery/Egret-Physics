## 2. 当前代码中的问题与待验证假设

### 2.1 可直接确认的实现问题

1. `solver.cpp::runNarrowPhaseCcdEvents()` 每对实体只装入一个 `contactData`。平面接触缺少覆盖支撑区域的多点流形，单个漂移的作用点容易产生交替力矩。
2. `continuous_collision_detector.h::extractContactFromGJK()` 在距离很小时使用 `posB-posA` 代替几何法线。平面对平面的法线不能由质心连线推导。地面中心与动态盒体相差很大的水平距离，回退方向可能产生虚假的水平冲量。
3. GJK 使用 A-B 闵可夫斯基差。分离时最近点 `pStar` 指向 B→A，但近接触回退中心方向指向 A→B；再加上类型注释和接触解算器约定相反，必须用交换 A/B 和已知轴向几何测试统一约定，不能只翻转一个分支。
4. `frictional_contact_resolver.cpp::solveSingleConstraint()` 只在法向相对速度为负时增加累积冲量。已经过量的累积冲量不能通过负增量回退，影响多点、多连接和热启动后的收敛。
5. 恢复项在迭代中直接使用当前相对速度，未固定冲击前的恢复目标，也没有低速恢复门限。恢复系数为 1 的场景尤其需要区分真实弹跳和接触稳定化。
6. 两个切向冲量各自夹到 `[-μλn,μλn]`，实际得到正方形截面，角部摩擦模长可达 `sqrt(2) μλn`，并非注释声称的圆锥。
7. 约束每次新建，累积冲量默认零；未见持久接触缓存回填。因此虽然有 `warmStart()`，当前主路径并未形成有效的跨帧热启动。
8. 两种接触解算器的位置循环均重复读取原始 `constraint.penetration`，没有更新修正后间隙，并且只平移、不修正转角。多个接触会重复补偿同一几何误差。
9. TOI 队列只在步初生成。某次冲量改变速度后，剩余事件时间与接触位置可能失效；当前仅取邻近 TOI 批次，不会自动包含同岛全部已有支撑接触。
10. 当前接触求解之后，积分器仍会加入场加速度。CCD 桥接采用恒速 Screw 模型而加速度为零，因此静止支撑中存在“解算后重新向下加速”的机制，需与积分阶段一起修复。
11. 离线 runner 调用 `world->tick()`，未调用 `world->endFrame()`；休眠计数却在 `onRenderFrameEnd()` 中推进。因此离线仿真创建了休眠策略，也不等于休眠计数正常推进。

这些是代码证据，不是本场景各因素影响大小的实验结论。尤其不能把所有抖动都归因于 EPA。

### 2.2 修复顺序

先统一几何与法线约定、生成稳定流形，再修复速度累积、摩擦和时间推进，最后接入全图位置补偿与仿真时间驱动的岛级休眠。只提高阻力或扩大冻结阈值，会掩盖底层问题。

## 4. 图的定义：接触多重图与约束岛

节点为动态刚体；同一实体对的流形是连接边，流形内每个点对应一条或多条标量约束。允许平行边、多连接节点和闭环，不能先抽取生成树丢掉其他边。

质量为零的地面是边界条件，逆质量和逆惯性均为零；不把地面当作普通节点，避免所有互不接触的物体经地面合成一个巨大岛。直接连接的动态刚体用并查集分岛。杆、关节等双边约束同样参与连通性；外力与空气阻力不形成岛边。

必须保留稳定实体 ID、子形状 ID、特征 ID、双方局部锚点、法线、间隙、历史冲量、接触年龄。数组索引只在本步有效，不能充当跨帧缓存键。

分析输出包括：每岛动态体数、流形数、约束行数、节点度数、静态边界数、独立环数，以及数值秩和条件估计。实体层的环数与约束行的线性相关不是同一件事；是否存在冗余最终由矩阵数值性质判断。

## 5. 位置层的统一数学模型

### 5.1 统一符号

后续实现统一令单位法线 n 从 A 指向 B。双方接触锚点为 pA、pB，间隙 C=n·(pB-pA)，正值分离、负值穿透。流形锚点必须来自两个形状表面，不能把当前单一中点同时当作双方锚点并假定 C 就是穿透。

第 i 个刚体小位姿变化为 ξi=(δxi,δθi)。令 rA、rB 为世界锚点相对质心的位置，单行雅可比为：

```text
Jc = [-nᵀ, -(rA×n)ᵀ, +nᵀ, +(rB×n)ᵀ]
C(q ⊕ ξ) ≈ C(q) + Jc ξ
```

固定体列从未知量中删除。没有转动自由度的实体也删去对应列。每次外迭代更新世界逆惯性和锚点。

### 5.2 质量加权最小修正

在同一份位姿快照上，为整岛求解：

```text
minξ  1/2 ξᵀ M ξ
s.t. J ξ ≥ b
```

M 是动态刚体的质量/世界转动惯性块矩阵。接触目标间隙取 `Ct=C+β max(-C-slop,0)`，因此 `b=Ct-C`：深穿透要求适度恢复，已接触或有正间隙的约束要求本轮不进一步关闭。单边接触允许分离。

将临近但未穿透的接触也纳入，否则补偿一条边会推穿另一条边。正间隙可选择允许关闭至安全裕量，但必须明确相应 b，不能直接忽略。

此目标让修正按物理质量和惯性共同分配；不是按节点度数平均，也不是把链式结果最后求和。

### 5.3 对偶形式与互补条件

不含双边约束时，令 `W=M⁻¹`：

```text
A = J W Jᵀ
minλ≥0  1/2 λᵀ A λ - bᵀ λ
ξ = W Jᵀ λ
w = A λ - b ≥ 0
λ ≥ 0，λᵀw = 0
```

共享刚体的约束通过 A 的非对角块耦合，环与多连接节点天然进入同一个系统。闭环导致的相关行可以使 A 半正定和对偶解不唯一；在正定质量度量及可行条件下，原始最小位姿修正仍唯一。

杆、关节的双边行写成 `Hξ=d`，相应乘子不施加非负限制，并与接触一起构建 KKT 系统。不能继续在全图修正之后逐条调用旧位置投影，否则会重新引入顺序依赖。

### 5.4 数值求解与退化处理

第一阶段优先小中型岛的主动集解法：维护接触活跃集合，解受限 KKT 系统；删除负接触乘子行、加入违反约束最严重的行，直到满足原始/对偶残差。排序只用于确定性破平局，不代替耦合求解。

使用带秩检测的分解处理冗余行；不能直接假定 `A` 正定然后无条件 Cholesky。重复接触可按几何特征合并，但不能任意删除真实闭环。

大型岛使用矩阵自由算子 `y=J(W(Jᵀx))` 和投影梯度/加速投影方法；接触块预条件仅用于加速。所有行在同一乘子快照上计算更新。若直接使用未阻尼 Jacobi，环和高连接节点不保证收敛，因此不得作为默认收敛保证。

矩阵自由乘法每轮成本随雅可比非零数增长；总成本仍依赖条件数和迭代轮数，不宣称整体线性时间。小岛直接分解也可能因填充有较高成本。

正则化 `A+εD` 只能作为有记录的数值兜底，会改变硬约束精度。原始约束确实不可行时，使用显式松弛变量 `s≥0`：`Jξ+s≥b`，目标增加 `ρ/2 ||s||²`；记录松弛量，不将其伪装成完全消除穿透。

### 5.5 同步提交与非线性外迭代

每个外迭代：

1. 冻结整岛当前位姿，更新流形锚点、间隙、雅可比和世界惯性。
2. 整体求解 ξ，所有实体位置保持不动。
3. 对整岛使用共同步长 α，限制最大平移与转角；不能逐实体独立夹断，破坏质量加权修正的平衡。
4. 将 `x←x+αδx`、`R←Exp(α[δθ]×)R` 一次性同步提交。
5. 重新计算真实几何间隙和双边误差；必要时回溯 α。若出现新接触或岛合并，更新图后重新求解。
6. 达到容差或预算后结束，输出未收敛残差和原因。

α<1 时允许只完成部分恢复，下一外迭代使用真实剩余误差。不得再次使用旧 penetration。不可行场景或预算耗尽应保留有界误差并报告，禁止偷偷切回链式补偿。

## 6. 速度层、静止接触与 CCD

位置投影不承担恢复和摩擦。速度层必须先修复现有逻辑：

- 每个冲击开始时保存冲击前 `vn_pre`，恢复目标 `vtarget=-e vn_pre`；仅对新冲击且速度超过明确门限时启用恢复。持续支撑目标通常为零。
- 法向更新为 `λnew=max(0,λold+(vtarget-vn)/kn)`，只施加差值；允许差值为负。
- 切向使用二维有效质量块，投影到圆盘 `||λt||≤μλn`，并重新评估法向修正后的相对速度。
- 持久化特征和局部锚点；缓存失配、法线大幅变化或实体删除时失效。切向历史冲量需投影到新切平面。
- 平面接触生成覆盖区域的稳定多点流形；盒体采用参考面/入射面裁剪，圆柱与凸网格通过对应几何特征或支撑面采样形成候选点，再按深度和覆盖面积缩减。具体形状不能一律硬取四个角。
- 近接触优先使用相容历史特征法线或真实面法线，不使用中心连线作为通用支撑法线。交换 A/B 后必须满足法线翻转、间隙不变。

时间推进应由统一调度器管理受力速度更新、CCD 与位姿推进。接触求解必须作用于本子步正确的受力速度，避免求解后又无约束加入一次重力。现有 Verlet 可保留在光滑无接触区；有接触区需明确定义分裂积分，而不能简单在当前积分器外再加一遍 `a·dt`。

每次 TOI 后更新受影响岛的候选事件，将同一时刻已有接触和双边约束一起求解。历史接触点必须变换至当前时刻；时间批次容差与子步尺度匹配，不把不同时刻的碰撞直接拼接成一张图。重复零 TOI 用持续接触分支和子步预算处理，不能无限循环。

复杂多体冲击本身需要明确响应模型；只修复位置层不能保证速度层无序列耗散。第二阶段可将整岛法向速度写成相同耦合结构，并选择明确的同时冲击规则；摩擦与恢复联合模型必须另行验证，不能直接把位置 QP 的结论当成冲击能量守恒证明。

休眠改为仿真时间驱动的岛级状态，结合低速度、低角速度、稳定接触与支撑条件；外力变化、接触拓扑变化、冲击或支撑消失应唤醒整岛。自由落体在最高点瞬时低速不得被冻结。离线和 GUI 使用相同计时语义。

## 7. 能量与动量的可保证范围

- 若位置阶段不改 v、ω，且只平移，则该阶段不直接改变平动与转动动能。
- 完整转角修正会改变世界惯性。若保持 ω，角动量与转动动能一般变化；若保持世界角动量 L 并重建 `ω=Iworld⁻¹L`，可保持该体 L，但转动动能仍可能变化。建议以 L 为角动量状态，明确记录这项变化，不能宣称所有量同时严格守恒。
- 无静态边界、无外部位置约束的内部成对平移修正在统一缩放下保持质量中心；单独钳制某个刚体会破坏这个性质。
- 位置变化改变重力势能；即使速度不变，也不能宣称机械能严格不变。
- 有固定地面时，地面是外部冲量来源，动态物体子系统的动量本来就不守恒；阻力、摩擦和 e<1 本来就耗能。
- 即使 e=1，多体同时冲击的恢复规则也不自动给出全系统能量守恒。评估时必须把模型耗散、外部做功与数值误差分开。

因此目标是消除可避免的顺序依赖、重复补偿和虚假冲量，而不是对所有场景承诺零能量误差。

| `ContactGraphBuilder` | 接触/关节多重图、动态岛、拓扑统计 |
| `GlobalPositionProjector` | 雅可比、质量加权 QP、同步非线性外迭代 |
| `ContactIslandSolver` | 统一调度速度、位置、TOI 和岛级休眠 |

复用 `src/model/solver/`、`src/model/strategy/` 现有职责，不将求解逻辑放进 ViewModel。两种接触策略共用位置投影器，避免修复一条路径而遗漏另一条。双边约束逐步提供行构建接口；未迁移前明确限制支持范围。

实施顺序：几何与符号回归 → 速度累积/恢复/摩擦 → 统一时间推进 → 全图位置层与双边行 → 缓存及岛级休眠 → 离线量化对比。每阶段都保留可定位的验证结果。

## 9. 验证计划（算法确定后的工作）

先跑独立数学与接触回归：

- 平面平行接触：中心与偏心放置、盒体与圆柱、交换 A/B、多点支撑下合力矩。
- 两体已知穿透：按逆质量分配；同一约束重复录入不应成倍推开。
- 三体环、四体闭环、星形高连接、桥接双岛、大质量比、重复共面行、固定体和双边约束。
- 随机置换实体/约束顺序，比较同步补偿结果与残差；全局求解到相同容差后，差异应仅为浮点误差量级。
- 分离中的过量历史冲量应能减小；摩擦模长不得超过圆锥界；自由落体最高点、撤走支撑、冲击唤醒。
- 单独检测位置阶段前后速度、质量中心和角动量状态，验证所宣称的边界。

之后才使用用户 `demo/test.epsx` 作为历史基线，先读取头信息与内嵌场景，确认确实匹配 `demo_world.epscene`。保存原文件，在新输出路径生成修复版本。另生成只含地面与一个动态实体的简化场景，分别设置无阻力、空气阻力、接触摩擦，不能把不同耗散混在一次结论中。

输出：接触法向偏差、角速度 RMS、尾段高度/姿态振幅、最大穿透、线性/角动量、平动/转动动能、势能、已知外力做功、QP 原始/对偶残差、未收敛数、耗时分位数。采样不足以捕获接触高频振荡时必须提高采样率，不能仅从抽帧曲线认定稳定。

阈值按场景单位、尺度、步长制定；单位语义需从序列化与 UI 核实。比较原算法和新算法时必须保持步长、采样率、恢复系数、阻力和初态一致。先在禁用休眠下验证接触稳定，再开启休眠验证最终停稳与唤醒。最终视觉效果由用户确认。

## 11. 首版实现与设计稿的对应关系

已实现：

- `ContactGraphProjector`：并查集动态岛、全部接触边、质量/惯性加权雅可比、稀疏矩阵自由对偶投影梯度、整岛共同步长、旋转锚点误差回溯和同步提交。旋转修正保持每体自旋角动量；不宣称保持总机械能或包含轨道项的总角动量。
- 为降低首版复杂度，小岛和大岛统一使用投影梯度，而非设计稿中的小岛主动集分解。使用 `|J| |W| |Jᵀ| 1` 给出安全步长上界，不显式构建接触数平方的稠密 A；冗余行和闭环不要求矩阵可逆。
- 杆的双边距离行、绳的单边最大距离行参与同一位置系统，并停止调用对应的旧链式位置修正。杆/绳的速度模型仍使用原有接口；其它旧约束类型尚未统一为图约束。
- 法向速度先用整体耦合系统求解，再用原有迭代结构耦合法向和二维圆锥摩擦。恢复目标只计算一次，累积法向冲量允许回退。同一步已处理的冲击不会在末尾支撑阶段重复恢复。
- 稳定盒体面裁剪、圆柱端面流形、球体/盒体几何接触；对其它支撑映射增加共面特征采集，不能形成有效支撑面时保留原 CCD 接触。并非所有形状组合都有专用流形构造器。
- 扫掠包围盒补充候选、TOI 后刷新、同一时刻已有支撑边合入求解、积分后支撑速度解算。保留原 Verlet 在光滑区的推进，未另写一套积分器。
- 接触模式休眠按仿真时间和接触岛推进；撤去支撑、改变受力、外部撞击可唤醒。旧独立休眠接口保留兼容。兼容配置 `frozenFrameCount` 在接触模式中按每单位 1/60 秒换算。
- 修复发现的盒体、圆柱、圆柱壳、凸网格惯性累加、凸网格质心偏移和实体合力的未初始化数据；惯性矩阵使用对称伪逆，支持零主惯量。

明确保留的边界：

1. 未增加跨帧接触缓存。调用方提供的初始冲量仍可使用，主路径每次重新求解；本次停稳验证不依赖缓存。
2. 未实现显式松弛变量、主动集、预条件加速和大型岛性能优化。有限迭代预算耗尽时记录残差与未收敛次数，不能据此声称任意复杂图均已精确求解。
3. 非线性外迭代更新旋转锚点，回溯局部几何约束误差；新接触通过调度器后续检测加入，不在投影器每次试探内部重新执行完整窄相位。对大幅补偿或接触拓扑剧变仍应重点验证。
4. 扫掠候选补充目前采用两两包围盒检查，最坏 O(N²)；数值投影虽使用稀疏矩阵自由乘法，整个流水线不能宣称线性复杂度。CCD 仍使用恒速运动假设，受加速度影响的穿透由后续接触恢复处理。
5. 平面特征、距离容差和恢复门限需要随场景数值单位调整；尤其 `restitutionVelocityThreshold=0.5` 表示当前场景单位下的速度，不应无条件迁移到其它尺度。

因此，这是能够运行并有回归验证的同步碰撞图首版，而非对任意形状、任意冲击模型或任意规模提供守恒及收敛保证的通用求解器。
